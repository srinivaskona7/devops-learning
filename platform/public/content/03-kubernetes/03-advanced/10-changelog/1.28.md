# Kubernetes 1.28 "Planternetes"

- **Release date**: 2023-08-15

## Summary
- **Native sidecar containers** introduced as alpha (`SidecarContainers`) — restartPolicy:Always init containers that run alongside main containers and terminate after them.
- Retroactive default StorageClass behavior reaches GA: PVCs created before a default StorageClass exists get bound when one appears.
- Control-plane / kubelet **version skew widened to n-3** for kubelet (was n-2) — easing upgrade cadence.

## Notable feature gate transitions

| Feature gate | Before | In 1.28 | Notes |
|--------------|--------|---------|-------|
| SidecarContainers | — | **alpha (off)** | restartPolicy:Always init containers |
| RetroactiveDefaultStorageClass | beta | **GA** | PVC defaulting fix |
| ConsistentListFromCache | — | **alpha** | apiserver list optimization (becomes important later) |
| ValidatingAdmissionPolicy | alpha | **beta (off)** | CEL-based admission, no webhook required |
| KubeProxyDrainingTerminatingNodes | — | **alpha** | better LB drain on terminating nodes |

## Notable deprecations / removals
- `ceph` and `glusterfs` in-tree volume plugins reach end-of-support timelines (verify with official release notes).
- Several legacy kube-controller-manager flags removed.

## Security
- Standard CVE patches in subsequent z-stream releases — verify with the official release notes.

## How to try sidecar containers (alpha)
```bash
# Enable with --feature-gates=SidecarContainers=true on apiserver, controller-manager, scheduler, kubelet.
```
```yaml
apiVersion: v1
kind: Pod
metadata: { name: web-with-log-shipper }
spec:
  initContainers:
    - name: log-shipper
      image: fluent/fluent-bit:latest
      restartPolicy: Always   # makes this a "native sidecar"
      volumeMounts:
        - { name: logs, mountPath: /var/log/app }
  containers:
    - name: web
      image: nginx:1.27
      volumeMounts:
        - { name: logs, mountPath: /var/log/nginx }
  volumes:
    - { name: logs, emptyDir: {} }
```
