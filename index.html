    DevOps Learning Lab¶

    Ten modules. Ten projects. One engineer, shaped for production.

    Start learning → Jump to projects

    🗺️ Curriculum map¶

    03

    Kubernetes¶

    Core · Strategies · Advanced — the heart of the curriculum. Pods to operators, rolling to GitOps.

    46 h · intermediate → expert

    01–02

    Foundations¶

    Linux internals, bash, systemd, Docker layers, BuildKit, Compose.

    22 h · beginner → intermediate

    04–07

    Platform layer¶

    Helm, Prometheus/Grafana/OTel, Security (SLSA L3), Terraform EKS.

    44 h · intermediate → expert

    08

    10 Projects¶

    Docker → GitOps → Progressive delivery → Platform engineering.

    80+ h · beginner → expert

    15

    AI for DevOps¶

    AIOps, Prompt Engineering for IaC, RAG for Runbooks, Platform Intelligence.

    16 h · intermediate → expert

    🛤️ Learning path¶

    01 · Linux fundamentals¶

    Filesystem, processes, signals, bash, systemd, networking, disk, troubleshooting. beginner — 12 h — Open →

    02 · Docker¶

    Images, Dockerfile, multi-stage, BuildKit, volumes, networks, Compose, security. beginner — 10 h — Open →

    03a · Kubernetes Core¶

    Cluster architecture, pods, deployments, services, ingress, RBAC, probes. intermediate — 16 h — Open →

    03b · Kubernetes Strategies¶

    Recreate, rolling, blue-green, canary, A/B, shadow, feature flags, Flagger, Argo Rollouts. intermediate — 12 h — Open →

    03c · Kubernetes Advanced¶

    CRDs, operators, HPA/VPA, PDB, admission controllers, service mesh, multi-cluster, eBPF/Cilium. advanced — 18 h — Open →

    04 · Helm¶

    Charts, templating, values precedence, hooks, helmfile, sealed-secrets. intermediate — 8 h — Open →

    05 · Monitoring & Observability¶

    Prometheus, PromQL, Grafana, Loki, Tempo, OTel SDK + Collector, SLO math, cardinality. intermediate — 12 h — Open →

    06 · Security¶

    STRIDE, RBAC, PSA, NetworkPolicy, SBOM, cosign, SLSA, OPA/Kyverno, Falco, IR playbook. advanced — 10 h — Open →

    07 · Terraform¶

    Providers, state, modules, workspaces, drift, CI/CD for IaC, testing (terratest, checkov). intermediate — 14 h — Open →

    08 · 10 Projects¶

    Docker hello-world → three-tier Compose → GitOps → CI/CD → observability → EKS → DR → security hardening → zero-downtime → platform engineering. expert — 80+ h — Open →

    10 · Python & Bash Scripting¶

    50 real-world automation examples · Bash foundations to advanced · Python to PhD level · All key DevOps libs covered. intermediate — Open →

    11 · 20 Trending DevOps Tools¶

    Basics to PhD per tool · 30 examples each · Mermaid architecture diagrams. GitHub Actions, Argo CD, Ansible, Vault, Istio, Falco, Karpenter, OTel and more. intermediate → expert — Open →

    12 · Go for DevOps¶

    Go foundations → concurrency → client-go → Docker SDK → Operators · 30 examples · From hello world to writing K8s controllers. advanced — Open →

    13 · Kubernetes Operators¶

    Build CRDs and operators from scratch — 10 real-world operator projects, RBAC, webhooks, testing

    14 · OPA & Kyverno¶

    Policy as Code — shift compliance left with Gatekeeper, Rego, Kyverno · 10 policy projects

    15 · AI for DevOps¶

    AIOps, LLMs for Infrastructure as Code, Intelligent Runbooks, and Platform Intelligence models. expert — Open →

    🔬 How each module teaches¶

    Every concept in this repo uses the same six-stage pattern:

    🧭 Reason¶

    Why this exists. The real problem it solves. A production incident that made it necessary.

    →
    🧠 Thinking¶

    Mental model + mermaid diagram. Build the map before you run the commands.

    →
    ⚡ → 🔮 → ✅ → 🌍¶

    Execute · Simulate · Output · Real-world use case at Netflix, Stripe, Cloudflare…

    Quick start¶

    # Clone
git clone https://github.com/<your-org>/Devops-learning.git
cd Devops-learning

# Install toolchain (macOS)
brew install docker kind kubectl helm terraform

# Run the docs site locally
pip install -r requirements.txt
mkdocs serve   # http://localhost:8000

# Jump into any project
cd 08-projects/01-hello-world-end-to-end
make up && make test && make perf && make down
