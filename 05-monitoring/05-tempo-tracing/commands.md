# Tempo & Tracing — Commands

> Quick pickup reference. Pair with `README.md` for theory.

## Setup

```bash
ls tempo-config.yaml
docker network create obs 2>/dev/null
```

## Run / deploy

```bash
# Tempo single-binary, OTLP gRPC :4317 / HTTP :4318, query :3200
docker run -d --name tempo --network obs \
  -p 3200:3200 -p 4317:4317 -p 4318:4318 \
  -v $PWD/tempo-config.yaml:/etc/tempo.yaml \
  grafana/tempo:2.6.0 -config.file=/etc/tempo.yaml
```

## Query / verify (TraceQL)

```bash
# Health
curl -s http://localhost:3200/ready
curl -s http://localhost:3200/status/version

# Lookup by trace_id (most common)
curl -s http://localhost:3200/api/traces/<TRACE_ID_HEX> | jq .

# Search via TraceQL (Tempo 2.x)
curl -sG http://localhost:3200/api/search \
  --data-urlencode 'q={ resource.service.name="checkout-svc" && duration > 500ms && status=error }' \
  | jq '.traces[] | {traceID, durationMs}'

# Tag / value discovery
curl -s http://localhost:3200/api/search/tags | jq .
curl -s http://localhost:3200/api/search/tag/service.name/values | jq .
```

### TraceQL patterns

```
{ resource.service.name="checkout-svc" }
{ duration > 500ms }
{ status = error }
{ resource.service.name="checkout-svc" && duration > 500ms && status = error }
{ span.http.status_code >= 500 }
```

## Send a test trace

```bash
# Via OTel CLI / collector — easiest is a tiny app emitting OTLP to :4317
# Or use grafana/xk6-client-tracing for synthetic load.
docker run --rm --network obs ghcr.io/grafana/xk6-client-tracing:latest \
  run --vus 1 --duration 30s -e ENDPOINT=tempo:4317 /scripts/basic.js
```

## Inspect

```bash
docker logs -f tempo | grep -iE 'error|ingest|compact'
docker exec tempo ls /var/tempo /tmp/tempo 2>/dev/null

# Span metrics generated by Tempo (if generator enabled) — scraped by Prometheus
curl -s http://localhost:3200/metrics | grep traces_spanmetrics
```

### Sampling reminder (lives in OTel Collector — see 06)

```
Head-based : decide at trace start (cheap, lossy).
Tail-based : collector buffers whole trace; keep all errors + slow + 1% normal.
```

## Cleanup

```bash
docker rm -f tempo
```

## One-liners worth memorising

```bash
# Pull a full trace as JSON for offline diffing
curl -s http://localhost:3200/api/traces/$TID | jq '.batches[].scopeSpans[].spans[] | {name, durationNano, status}'

# Quick "anything errored in last 5m?"
curl -sG http://localhost:3200/api/search --data-urlencode 'q={ status=error }' | jq '.traces | length'
```

```
trace = DAG of spans, propagated via W3C traceparent header.
Tempo stores in object storage (S3/GCS/Azure) -> cheap "always on" tracing.
Search by trace_id is free; TraceQL search needs the search index.
Pick Tempo when you live in the Grafana stack; Jaeger when you want rich UI search at smaller scale.
```
