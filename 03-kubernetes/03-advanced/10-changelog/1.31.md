# Kubernetes 1.31 "Elli"

- **Release date**: 2024-08-13

## Summary
- **PersistentVolume `lastPhaseTransitionTime`** reaches **GA**, providing accurate timestamps for PV phase changes — useful for storage SRE/observability.
- **kube-proxy nftables backend** reaches **beta** as a faster, more scalable alternative to iptables for clusters with many Services.
- All in-tree cloud provider integrations are now removed from the Kubernetes binary tree (the Cloud Provider Extraction project completes) — clusters must use external cloud-controller-manager.

## Notable feature gate transitions

| Feature gate | Before | In 1.31 | Notes |
|--------------|--------|---------|-------|
| PersistentVolumeLastPhaseTransitionTime | beta | **GA** | new field on PV status |
| NFTablesProxyMode | alpha | **beta** | `kube-proxy --proxy-mode=nftables` |
| AppArmorFields | GA (since 1.30) | GA | confirmed stable |
| AnonymousAuthConfigurableEndpoints | — | **alpha** | restrict anonymous to specific endpoints |
| PodHostIPs | beta | **GA** | dual-stack pod host IPs in status |
| ServiceTrafficDistribution | — | **beta** | `spec.trafficDistribution: PreferClose` for topology-aware routing (replaces the older topology-aware-hints UX) |
| JobSuccessPolicy | alpha | **beta** | declare success when a subset of indexed pods finish |

## Notable deprecations / removals
- All in-tree cloud providers (AWS, Azure, GCE, vSphere, OpenStack) finally **removed** from kube-apiserver / kube-controller-manager / kubelet — must run external CCM. Operators should have migrated by now.
- Legacy `topology.kubernetes.io/zone` hints behavior superseded by `trafficDistribution`.

## Security
- Anonymous auth can now be scoped to only `/healthz`, `/livez`, `/readyz` via the alpha gate — defence-in-depth for clusters that previously had to keep anonymous on for health checks.

## How to try traffic distribution
```yaml
apiVersion: v1
kind: Service
metadata: { name: my-svc }
spec:
  selector: { app: my-app }
  ports: [{ port: 80, targetPort: 8080 }]
  trafficDistribution: PreferClose   # prefer endpoints in the same zone
```
