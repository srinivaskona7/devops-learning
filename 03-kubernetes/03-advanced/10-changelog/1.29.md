# Kubernetes 1.29 "Mandala"

- **Release date**: 2023-12-13

## Summary
- **ReadWriteOncePod** PV access mode reaches **GA** — true single-pod write semantics, useful for leader-elected stateful apps.
- **Native sidecar containers** moves to **beta and on by default** (the `SidecarContainers` gate) — production paths can adopt with caution.
- **KMS v2** envelope encryption for secrets reaches **GA** — improved performance, key rotation, observability vs v1.

## Notable feature gate transitions

| Feature gate | Before | In 1.29 | Notes |
|--------------|--------|---------|-------|
| ReadWriteOncePod | beta | **GA** | new PV access mode |
| SidecarContainers | alpha | **beta (on)** | default-enabled |
| KMSv2 / KMSv2KDF | beta | **GA** | use envelope encryption v2 in EncryptionConfiguration |
| APIPriorityAndFairness | beta | **GA** | request fairness in apiserver |
| CRDValidationRatcheting | — | **alpha** | re-validate only changed fields on update |
| PodReadyToStartContainersCondition | alpha | **beta** | finer-grained pod conditions |

## Notable deprecations / removals
- In-tree **vSphere** and **Azure file** legacy volume plugin paths continue migration to CSI; in-tree code increasingly removed in following releases.
- Legacy beta APIs that hit their N+3 window get removed (verify with official release notes).

## Security
- KMS v1 deprecated; plan migration to v2.
- Track CVEs in patch releases; nothing release-defining for 1.29 specifically.

## How to try KMS v2
```yaml
# /etc/kubernetes/encryption-config.yaml on the control plane
apiVersion: apiserver.config.k8s.io/v1
kind: EncryptionConfiguration
resources:
  - resources: ["secrets"]
    providers:
      - kms:
          apiVersion: v2
          name: my-kms
          endpoint: unix:///var/run/kmsplugin/socket.sock
          timeout: 3s
      - identity: {}
```
