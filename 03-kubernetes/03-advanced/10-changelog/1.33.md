# Kubernetes 1.33 "Octarine"

- **Release date**: 2025-04-23

## Summary
- **Sidecar containers reach GA** — restartPolicy:Always init containers are now a stable feature.
- **In-place pod resize** moves to **beta and on by default** — change CPU/memory requests/limits without restarting the pod (long-awaited).
- **User namespaces for pods** (`UserNamespacesSupport`) reach **GA**, and **multiple Service CIDRs** reach **GA** — networking can grow Service ranges without recreating the cluster.

## Notable feature gate transitions

| Feature gate | Before | In 1.33 | Notes |
|--------------|--------|---------|-------|
| SidecarContainers | beta | **GA** | restartPolicy:Always init container is a stable concept |
| InPlacePodVerticalScaling | beta | **beta (on)** | default-on; resize without restart for most resources |
| UserNamespacesSupport | beta | **GA** | rootless-style isolation for pods |
| MultiCIDRServiceAllocator + ServiceCIDRsRollout | beta | **GA** | expand Service IP ranges via `ServiceCIDR` and `IPAddress` objects |
| NFTablesProxyMode | beta | **GA (likely)** | verify with official release notes |
| PodLifecycleSleepAction | beta | **GA** | `preStop.sleep` without exec'ing into the container |
| JobSuccessPolicy | beta | **GA (likely)** | verify with official release notes |
| TopologyAwareHints | GA | GA | continues to be the underlying mechanism for `trafficDistribution` |

## Notable deprecations / removals
- The legacy single Service CIDR flag-only configuration is superseded by `ServiceCIDR` objects — operators should use the API.
- Various long-beta gates that graduated to GA had their gate options become no-ops (cannot disable anymore).

## Security
- User namespaces GA materially reduces blast radius of container escapes — turn it on where your runtime supports it (containerd ≥ 1.7 on a recent kernel).

## How to try in-place pod resize
```bash
# Edit live:
kubectl patch pod my-app --subresource resize \
  --patch '{"spec":{"containers":[{"name":"app","resources":{"requests":{"cpu":"500m"},"limits":{"cpu":"1"}}}]}}'

# The pod's QoS class may NOT change as part of a resize (validation rejects it).
# Memory shrink may be denied by the kernel; CPU resize is generally hot.
```

## How to try multiple Service CIDRs
```yaml
apiVersion: networking.k8s.io/v1
kind: ServiceCIDR
metadata: { name: extra }
spec:
  cidrs: ["10.96.0.0/16", "10.99.0.0/16"]
```
