What to try next

  1. Probe the headers. curl -I http://localhost:8080/ — confirm X-Frame-Options, X-Content-Type-Options, and the absent Nginx version string.
  2. Break the rootfs. docker exec hello touch /bad — the read-only filesystem refuses the write. That's your security control working.
  3. Load test it. make perf — 50 virtual users for 2 minutes. Watch p95 hover under 50 ms.
  4. Ship it. Tag ghcr.io/you/hello-world:0.1.0, push, and pull from another machine. Same bytes. Same behaviour. That's immutable delivery.
