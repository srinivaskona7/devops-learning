# Kubernetes 1.30 "Uwubernetes"

- **Release date**: 2024-04-17

## Summary
- **ValidatingAdmissionPolicy** reaches **GA** — declarative CEL-based admission validation built into the apiserver, no webhook to operate.
- **AppArmor** support reaches **GA** — first-class `securityContext.appArmorProfile` field instead of the legacy annotation.
- **Structured authentication configuration** (file-based authenticator config with multiple OIDC providers and CEL claim mapping) reaches beta.

## Notable feature gate transitions

| Feature gate | Before | In 1.30 | Notes |
|--------------|--------|---------|-------|
| ValidatingAdmissionPolicy | beta | **GA** | use CEL `MatchConditions` and `Validations` |
| AppArmorFields | — | **GA in 1.30** | move from annotations to `securityContext.appArmorProfile` |
| StructuredAuthenticationConfiguration | alpha | **beta** | multiple OIDC issuers, CEL claim mapping |
| ContextualLogging | beta | **beta** | logger context propagation; nearing GA |
| MinDomainsInPodTopologySpread | beta | **GA** | `minDomains` for spread |
| WatchList | alpha | **beta (off)** | streaming list responses |
| PodDisruptionConditions | beta | **GA** | DisruptionTarget pod condition |

## Notable deprecations / removals
- Legacy `container.apparmor.security.beta.kubernetes.io/...` annotations deprecated in favor of the new field.
- SecurityContextDeny admission plugin removed (verify with official release notes).

## Security
- ValidatingAdmissionPolicy lets you replace many policy webhooks — fewer moving parts, smaller blast radius.
- Patch-level CVEs as usual; check the security advisories.

## How to try ValidatingAdmissionPolicy
```yaml
apiVersion: admissionregistration.k8s.io/v1
kind: ValidatingAdmissionPolicy
metadata:
  name: deny-latest-tag
spec:
  failurePolicy: Fail
  matchConstraints:
    resourceRules:
      - apiGroups: [""]
        apiVersions: ["v1"]
        operations: ["CREATE","UPDATE"]
        resources: ["pods"]
  validations:
    - expression: "object.spec.containers.all(c, !c.image.endsWith(':latest'))"
      message: "image tag :latest is not allowed"
---
apiVersion: admissionregistration.k8s.io/v1
kind: ValidatingAdmissionPolicyBinding
metadata: { name: deny-latest-tag-binding }
spec:
  policyName: deny-latest-tag
  validationActions: [Deny]
  matchResources:
    namespaceSelector:
      matchLabels: { env: prod }
```
