# Kubernetes 1.27 "Chill Vibes"

- **Release date**: 2023-04-11

## Summary
- `SeccompDefault` graduated to **GA** — kubelet can default all workloads to `RuntimeDefault` seccomp profile.
- Job APIs evolve: pod failure policy and **mutable scheduling directives** for suspended Jobs help batch/ML workloads.
- Many alpha → beta promotions across the API; `kubectl apply --prune` got a new ApplySet-based mode (alpha).

## Notable feature gate transitions

| Feature gate | Before | In 1.27 | Notes |
|--------------|--------|---------|-------|
| SeccompDefault | beta | **GA** | kubelet `--seccomp-default` flag stable |
| JobMutableNodeSchedulingDirectives | beta | **GA** | edit nodeSelector/affinity on suspended Jobs |
| DownwardAPIHugePages | beta | **GA** | expose hugepages requests/limits via downward API |
| ServerSideFieldValidation | beta | **GA** | server validates unknown/duplicate fields |
| OpenAPIV3 | beta | **GA** | apiserver publishes OpenAPI v3 |
| KubeletInUserNamespace | alpha | alpha | rootless kubelet experiments continue |

## Notable deprecations / removals
- In-tree cloud providers continue migrating to out-of-tree (CCM); several flags marked deprecated.
- `seccomp.security.alpha.kubernetes.io/pod` annotation long-deprecated; use `securityContext.seccompProfile`.

## Security
- No release-defining CVE tied to 1.27 itself; track patch releases for CVE fixes.

## How to try SeccompDefault
```bash
# Start kubelet with:
#   --seccomp-default=true
# Then any pod without an explicit seccompProfile uses RuntimeDefault.
kubectl run demo --image=nginx:1.27 --restart=Never
kubectl get pod demo -o jsonpath='{.spec.containers[0].securityContext}'
```
