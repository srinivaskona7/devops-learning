# Kubernetes 1.32 "Penelope"

- **Release date**: 2024-12-11

## Summary
- **Dynamic Resource Allocation (DRA)** moves to **beta** with a redesigned, "structured parameters" API — the long-term path for GPUs, FPGAs, and other accelerators.
- **Anonymous auth restrictions** (`AnonymousAuthConfigurableEndpoints`) reach beta — clusters can finally allow anonymous on a tight allowlist (e.g., only health endpoints).
- **Custom profiling endpoints** in components and other API-machinery hardening land; many small UX improvements (verify with official release notes for full list).

## Notable feature gate transitions

| Feature gate | Before | In 1.32 | Notes |
|--------------|--------|---------|-------|
| DynamicResourceAllocation | alpha | **beta (off)** | new structured-parameters model |
| AnonymousAuthConfigurableEndpoints | alpha | **beta** | scope anonymous auth |
| KubeletFineGrainedAuthz | — | **alpha** | finer authorizer hooks for kubelet |
| ConsistentListFromCache | beta | **GA** | apiserver serves consistent lists from the watch cache (big perf win) |
| RetryGenerateName | alpha | **beta** | retry on `generateName` conflicts |
| StatefulSetStartOrdinal | beta | **GA** | start-ordinal offset for StatefulSets |
| RecoverVolumeExpansionFailure | beta | **beta** | continues maturation |

## Notable deprecations / removals
- Older DRA API (`resource.k8s.io/v1alpha2`) removed in favor of the new structured-parameters API — driver and workload manifests must be migrated.
- Continued cleanup of long-deprecated flags (verify with official release notes).

## Security
- Hardened anonymous auth defaults via the new gate.
- Standard CVE backports.

## How to try DRA (beta)
```yaml
# Requires --feature-gates=DynamicResourceAllocation=true on apiserver, scheduler, kubelet,
# plus a DRA driver installed (e.g., NVIDIA DRA driver).
apiVersion: resource.k8s.io/v1beta1
kind: ResourceClaimTemplate
metadata: { name: gpu-claim-template }
spec:
  spec:
    resourceClassName: gpu.nvidia.com
---
apiVersion: v1
kind: Pod
metadata: { name: dra-demo }
spec:
  resourceClaims:
    - name: gpu
      resourceClaimTemplateName: gpu-claim-template
  containers:
    - name: app
      image: nvidia/cuda:12.4.0-base-ubuntu22.04
      resources:
        claims:
          - name: gpu
```
